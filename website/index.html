THE EDGE

Your audio takes the short route.

The Jetson captures audio in four-second windows and runs NVIDIA NeMo speech recognition locally. Rolling mode keeps a bounded minute of recent text while capture continues during decoding.

Raw audio stays on the device

Only selected text goes to the cue model. Optional AWS storage holds portfolio snapshots and timestamped summaries—not raw recordings.

EDGE / NVIDIA JETSON ORIN NANO

Close to the conversation.

Capture
sounddevice / PortAudio · 16 kHz mono · four-second windows
Recognition
NVIDIA NeMo Conformer CTC Small · approximately 13M parameters
Rolling context
60 seconds · up to 15 fragments / 3,600 characters · recent text expires in RAM
Pause heuristic
At least 1s accumulated speech + 3s silence + 30s cooldown

Rolling mode keeps capture running during decoding. Audio energy is a heuristic; a pause does not establish hesitation or anxiety.

02 / SHADOW MODE

Observe first. Validate next.

The optional local adapter scores five-second audio windows every four seconds, alongside ASR. Scores never trigger cues. Evaluation compares fluent speech, acted hesitation, quiet, and partner-only speech.

The source reports 59.27% test accuracy and about 53% stuttering recall at threshold 0.5. Speaker-independent generalization remains unverified; these are not anxiety measurements.

DESIGNED WITH CARE

Helpful should
feel respectful.

You decide when to use a cue. The system doesn’t decide who you are or how you feel.

01

Audio stays local.

The prototype processes raw microphone audio on the Jetson. It does not send recordings to NaviGator or S3.

02

Cloud context has boundaries.

Only bounded, selected text and optional portfolio facts go over HTTPS. Recent context expires in RAM; no full transcript archive is created. Optional S3 summaries and portfolio snapshots persist until deleted or expired. Selected text can still contain personal information.

03

A cue is a suggestion.

Pauses are not diagnoses. The prototype does not identify speakers or reliably detect anxiety. It is not a clinical diagnostic tool, speaker verifier, or medical device. Cues can be wrong, and you can ignore them.

THE CONTROLS STAY WITH YOU

A few commands.
Room to experiment.

Type each command and press Enter. Use synthetic examples for demonstrations.

:cue
Request a cue from recent context.
:check
Inspect context counts and portfolio matches locally. No API request.
:pause / :listen
Stop or resume microphone listening.
:forget
Clear the local summary and recent context. Saved S3 records remain.
:quit
End the session. With S3 enabled, a pending summary may be saved.

07 / THE NEXT CHAPTER

A more thoughtful
kind of assistance.

Research directions. Open each one to see the question behind it.

01 / TIMINGSmarter pause understanding +

Can we distinguish an ordinary conversational pause from a moment when support would be welcome? Evaluate false alarms, missed opportunities, and user control.

02 / SIGNALSSpeech–disfluency fusion +

Study acoustic disfluency features together with silence and text context. Validate on consenting participants and held-out speakers before enabling new automatic triggers.

03 / WHO’S SPEAKINGSpeaker-aware context +

Explore diarization and user enrollment to separate conversational turns. Today, microphone text is speaker-unknown; speaker verification is not implemented.

04 / EVERYDAY USEWearable, responsive design +

Measure end-to-end latency and investigate compact interfaces and smaller local models. Aim for discreet assistance that leaves attention on the conversation.

A few good questions.

Is this website listening to me?

No. This page is a static project showcase. The interactive example uses prewritten fictional dialogue and makes no microphone or AI requests. The actual prototype runs separately on a Jetson.

Does Co-Wingman detect anxiety?

No validated anxiety detection is claimed. Pause assistance uses an audio-energy heuristic. The optional experimental model was trained on stuttering/control labels, which cannot establish a person’s emotional state.

Can it tell my voice from someone else’s?

Not yet. Microphone fragments are marked speaker-unknown. Speaker verification and diarization are future work; a nearby conversation partner can affect recognition and pause detection.

What gets saved?

Recent conversation text is bounded and held in memory. Optional S3 features persist portfolio snapshots and timestamped summaries. This website does not store your demo selections or request account information.
