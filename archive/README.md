# Historical evidence — not the application

These documents and the isolated local-LLM benchmark record earlier research.
Their setup commands, provider choices, stop instructions, and acceptance criteria
are obsolete. Do not use them to launch Co-Wingman. Use the root README instead.

The October 14, 2026 physical Jetson run identified an Orin Nano 8 GB on
L4T 36.4.7. Local Nemotron left approximately 294 MiB available RAM, used
4.47 GiB server RSS, and grew swap by 361 MiB. Local Nemotron is therefore
excluded from the product. Generated reports are no longer tracked.

The historical benchmark's parsing/resource tests remain as regression coverage;
the former Nebius boundary tests were replaced by stricter NaviGator tests.
